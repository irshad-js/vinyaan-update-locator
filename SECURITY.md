# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to the repository owner, Irshad Ahamed
(irshad.ahamed@pradint.com). Do not open a public issue, pull request or discussion for a
security problem.

Include the affected commit or version, how to reproduce the problem, and what
an attacker could achieve. Do not test against live boards, classrooms or
services you do not own. The owner acknowledges reports and coordinates any
fix and disclosure.

## Scope

The signed extension locator, catalogue and artifacts mirrored from the LMS,
and the GitHub Pages workflow that publishes them. Signature or catalogue
problems in the consumers belong here too.

## Supported versions

Security fixes go to the current default branch and, through it, to the
revision pinned by the accepted workspace lock
(`vinyaan-workspace/workspace.lock.json`). Older revisions are not maintained.
